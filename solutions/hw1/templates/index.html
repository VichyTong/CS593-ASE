MODEL CONNECTION

Model setup

Create .env in the application folder using .env.example. Set your provider's values, then restart the server:

LLM_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=your-private-api-key
LLM_MODEL=gpt-6-luna

For Ollama, use http://localhost:11434/v1, key ollama, and an installed model name. Keys stay on the server.

AI actions send extracted paper text to your configured model provider. Search, saving, and PDF reading work without a model.
